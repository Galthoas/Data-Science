# Data Science Career Roadmap — Business Support Technician → Data Scientist

**Owner:** Ernest Braswell
**Starting point:** B.S. from MTSU, currently working as a Business Support Technician
**Target:** Job-ready Data Scientist — professional-practitioner depth, built entirely from free coursework from Harvard, MIT, Stanford, Google, IBM, and other top sources
**Pace:** ~10–15 hrs/week
**Estimated timeline:** 12–18 months
**Estimated total study time:** ~650–950 hours

This repository is your complete self-study curriculum, progress tracker, and portfolio home. Everything in it is designed around courses that are **free to learn from** (you only ever pay, optionally, for an official certificate/credential once you already know the material works for you).

## How to use this repo

1. Start at [`ROADMAP.md`](ROADMAP.md) to see the whole plan.
2. Work through `phases/00-setup` first — it's short and gets your tools (Python, Git, GitHub, a code editor) working.
3. Go phase by phase, in order. Each phase README tells you exactly what to do and what "done" looks like.
4. Check items off in [`progress-tracker.md`](progress-tracker.md) as you finish them, and commit your progress to this repo regularly — the commit history becomes proof of consistent, sustained work, which matters to hiring managers almost as much as the skills themselves.
5. Every phase from Phase 3 onward produces something for [`projects/`](projects/) — real, documented work that becomes your portfolio.

## Why this path gets you there

Employers hiring for "Data Scientist" roles are overwhelmingly checking for four things: solid statistics/math fundamentals, programming fluency (Python + SQL), practical machine learning skill, and evidence you can do real analysis end-to-end (a portfolio). This roadmap builds all four using some of the same courses actual Harvard, MIT, and Stanford students take (CS50, 18.06 Linear Algebra, 18.05 Probability & Statistics, HarvardX's Professional Certificate in Data Science, and Stanford/DeepLearning.AI's Machine Learning Specialization), plus the two most recognized industry certificates (Google's and IBM's Professional Certificates on Coursera). None of it requires paying tuition; the only optional costs are certificate fees, covered in [`CERTIFICATION-PATHS.md`](CERTIFICATION-PATHS.md), including how to get them waived via financial aid.

"Equivalent to doctorate-level training" is a high bar that in the strictest sense means original research and a dissertation — that's not what a self-study plan can replicate, and you should feel free to say so plainly in interviews. What this roadmap *can* do, and does, is take you to genuine practitioner mastery: the same math foundations, the same core methods, and the same tools a working PhD-trained data scientist uses day to day, verified through real projects rather than a credential alone.
