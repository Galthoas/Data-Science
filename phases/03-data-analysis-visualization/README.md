# Phase 3 — Data Analysis & Visualization (6–8 weeks, ~90 hrs)

Goal: the actual day-to-day craft of data analysis — loading messy real-world data, cleaning it, exploring it, and communicating findings visually. This is the most immediately job-relevant phase so far; it maps directly onto what a Data Analyst (and much of what a Data Scientist) does daily.

## Courses

### 1. Kaggle Learn — Python, Pandas, Data Visualization, Data Cleaning
**~15–20 hrs total** (each micro-course is 3–5 hrs, free, no signup friction beyond a Kaggle account).
- https://www.kaggle.com/learn
- Specifically: "Python," "Pandas," "Data Visualization," and "Data Cleaning" tracks. Each ends in hands-on exercises graded instantly, and a shareable completion certificate.
- These are short and dense — the best "get productive fast" resource in this whole roadmap.

### 2. freeCodeCamp — Data Analysis with Python Certification
**~20–25 hrs** for the certification track (there's also a shorter 4-hr overview video if you want a preview first).
- https://www.freecodecamp.org/learn/data-analysis-with-python
- Covers NumPy, Pandas, Matplotlib, and finishes with 5 real graded projects you build yourself — demographic data analysis, sea level prediction, and others that can go straight into your portfolio.

### 3. Google Data Analytics Professional Certificate (audit)
**~40–50 hrs** if you audit just the technical modules (the full certificate track, including all reflection/quiz content, runs ~180 hrs across ~6 months at Google's suggested pace — you can move much faster).
- https://www.coursera.org/professional-certificates/google-data-analytics
- This is an industry-standard, employer-recognized certificate (see [`CERTIFICATION-PATHS.md`](../../CERTIFICATION-PATHS.md) for how to get it free via financial aid rather than skimming it via audit-only). It's heavier on process and tooling (spreadsheets, Tableau, SQL, R) than the other courses in this phase, and is the piece of this roadmap most directly aimed at passing an employer's "do you know the standard data analyst toolkit" bar.

## Suggested order

1. Kaggle Learn tracks first — fast wins, builds momentum.
2. freeCodeCamp Data Analysis with Python next — deepens pandas/matplotlib fluency and produces your first portfolio-ready projects.
3. Google Data Analytics Professional Certificate alongside or after — it's the most "credential-shaped" piece of this phase and can run in the background over several weeks.

## Portfolio output

By the end of this phase you should have your **first EDA (exploratory data analysis) project** ready for `projects/` — pick a public dataset (Kaggle datasets, data.gov, or one from the freeCodeCamp projects) that genuinely interests you, and produce a clean Jupyter notebook that loads it, cleans it, explores it with visualizations, and states 2–3 concrete findings in plain English. See [`projects/README.md`](../../projects/README.md) for the full requirements.

## You're done when

- You can take a messy, real-world CSV and turn it into a clean pandas DataFrame without hand-holding.
- You can produce a matplotlib/seaborn chart that actually communicates a finding clearly, not just "a chart that exists."
- You have one finished EDA project pushed to this repo's `projects/` folder with a clear README.
